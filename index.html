FAQ

常見問題

我嘅錄音會唔會畀人聽到？ ⌄
完全唔會。我哋係 desktop app，錄音永遠喺你部電腦處理，唔會上傳去任何 cloud server。同 Otter.ai、Fireflies 嗰啲完全唔同（佢哋會上傳）。
廣東話準確度幾多？ ⌄
純廣東話 95%+，中英夾雜 90%+，普通話 95%+。基於 OpenAI 嘅 Whisper Large-v3 模型，係目前最強嘅多語言模型。
支援咩平台？ ⌄
Windows 10/11（依家支援）。Mac 版本 Q4 2026 推出，可以加入 waitlist。
處理 1 小時錄音要幾耐？ ⌄
視乎你電腦規格 ——
  • 普通 laptop（i5/i7）：~30-60 分鐘
  • 新 CPU（M1/M2 / Lunar Lake）：~15-25 分鐘
  • 有 NVIDIA GPU：~5-10 分鐘
會唔會收 hidden fee？ ⌄
完全冇。價錢就係 HKD 99/月（早鳥），所有功能無限用。AI 處理嘅 cloud cost 我哋幫你付，你只係付月費。
同 ChatGPT / Otter 有咩唔同？ ⌄
  • 廣東話：Otter、Fireflies 唔識；ChatGPT 唔處理錄音
  • 私隱：我哋本地處理；其他全部上 cloud
  • 專業：我哋特別為會計、律師、醫生優化 prompt
  • 記憶：我哋有 RAG，可以問過往 100 個會議
點 cancel subscription？ ⌄
隨時 cancel，唔 lock 你。我哋透過 Stripe 處理，account 入面一 click 即時 cancel，今個月用完就無 charge 下個月。
支援團隊用嗎？ ⌄
支持，揀「團隊版」可以 5 個用戶共享 client 資料庫 + admin dashboard。大型 deployment（10+ 用戶）請聯絡 sales 攞 quote。
